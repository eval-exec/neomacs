The observation probes in this directory and `native_contract.py` serve different purposes. `probe.py` records external requests without asserting which native callback ran; its historical `menu` action injects Command-Q. `native_contract.py` asserts the installed native callbacks and the resulting Lisp query hook on both editors.

Run the contract on a logged-in macOS desktop, after `cargo xtask fresh-build --release` in the same guarded remote job:

```sh
python3 scripts/macos-quit-parity/native_contract.py --gnu-prefix "$GNU_ORACLE_PREFIX"
```

The oracle must pass `scripts/ci/check-gnu-oracle.sh` as GNU 31.1 at `a360712c9d272d950d8d8255ef74570f7e90b7d9`, with the `macos-ns` profile. The script prints the check output, binary hashes, binding form, and every result, and writes artifacts under its own `tmp/native-quit-contract-*` directory. An injection, readiness, or required callback failure returns nonzero. Physical Command-Q prerequisites are reported separately as BLOCKED; `--physical` also makes those prerequisites mandatory. No permissions are requested or changed.

The test-only dylib loads into each harness-owned editor. It dispatches the actual application-menu Quit item's target/action, calls `terminate:`, or directly calls the installed delegate's `applicationShouldTerminate:`. A wrapper on that delegate class counts calls and forwards to the unchanged original implementation with its exact SDK signature. It neither replaces termination decisions nor installs a different delegate. Each result identifies the child PID, loaded driver image, delegate class, original/wrapper implementations, and native alert button. The alert driver uses the modal run-loop mode and only touches the owned child's modal window. A parent deadline and child-only teardown bound failures.

The quit AppleEvent targets the owned PID. Its delegate-call count and reply come from the live GNU arm, because AppKit can ask the delegate before calling the overridden `terminate:`. They are compared directly with Neo, not pinned to a host-dependent literal. The Lisp fixture retains `[ns-power-off]`'s default `save-buffers-kill-emacs` binding and vetoes termination in `kill-emacs-query-functions`. It records the command, query and kill-hook counts before teardown, and requires the original Lisp command to return after the veto. A rebound `s-q` witness uses `execute-kbd-macro` and is explicitly separate from physical key input. The native menu action is not an Accessibility click or proof of physical Command-Q delivery. GNU can run `kill-emacs-hook` during SIGTERM teardown; frozen before-teardown observations distinguish that cleanup from the quit request under test.

The pinned GNU contract is in `src/nsterm.m:6095-6097,6588-6641`, `src/nsmenu.m:519-525`, `lisp/term/ns-win.el:141,177,195`, `src/nsterm.m:11653-11655`, and `lisp/files.el:8541-8553,8571-8641`. GNU overrides `terminate:` and queues the non-key `ns-power-off` event without calling its superclass. Menu Quit therefore reaches Lisp's query hook independently of the rebound key and without calling the delegate. The delegate's separate native alert returns `NSTerminateNow` or `NSTerminateCancel` according to `ns-confirm-quit` and the selected button.

[AppKit documents the delegate's termination decision](https://developer.apple.com/documentation/appkit/nsapplicationdelegate/applicationshouldterminate(_:)). Its general menu-to-delegate description applies to the superclass implementation; GNU's override is the compatibility contract here. The existing Neomacs input bridge and scalar host publication remain the product seams. The helper supplies observations at the native boundary without adding an arbitrary selector API to the product.
