NEO Emacs for macOS — unnotarized build

This copy was built without Developer ID credentials, so it is ad-hoc signed.
Apple therefore cannot identify or notarize its publisher.

If macOS blocks the app:

1. Drag neomacs.app to Applications.
2. Try to open it once.
3. Open Apple menu > System Settings > Privacy & Security.
4. Scroll to Security and click Open Anyway for NEO Emacs.
5. Confirm Open when macOS asks again.

This per-app exception is Apple's supported override. Do not disable
Gatekeeper globally.

Apple's current instructions:
https://support.apple.com/guide/mac-help/mh40616/mac
