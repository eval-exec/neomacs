# core_test_facades — cfg(test)-only wrappers for Prep D's relocated tests

Generated by `tmp/v10x/tools/move-wrappers.py` from:
- the extraction manifest (`current-manifest.tsv`), and
- oracleb's `decl-handoff.tsv` (47 declarations; 44 in moving parents).

These are **declaration-only** core wrapper modules at the historical module
paths of the 44 relocated test declarations that sit in parents moving to
`neovm-value`. In a test build each wrapper glob-re-exports the moved value
module, declares child wrapper modules, and hosts the relocated test
declaration; in a product build the plain `pub use neovm_value::<module>`
facade is used and this tree is not compiled. No wrapper holds test logic or
product items.

The tree lives outside `src/` (like `core_tests/`) so source scanners never
see it and the manifest walker skips it.

## Installation (atomic move)

`core_test_facades-snippets.txt` holds the cfg-split facade lines to place in
`src/lib.rs` and `src/emacs_core/mod.rs`:

    #[cfg(not(test))]
    pub use neovm_value::tagged;
    #[cfg(test)]
    #[path = "../core_test_facades/tagged.rs"]
    pub mod tagged;

The atomic move also deletes the corresponding `#[cfg(test)] #[path = ...]
mod <name>;` blocks from the moving parents (allowed by the neutrality tool as
test-declaration wiring; see `move-body-diff.py`).

## Regeneration

After Prep D's handoff grows (C splits) or the manifest changes, re-run:

    move-wrappers.py --manifest current-manifest.tsv \
      --handoff decl-handoff.tsv --core-root crates/neovm-core \
      --out-root <dir> --self-test

`--check` verifies the 44 declarations, exact module-path reconstruction and
that every test target resolves. `--self-test` compiles the tree against an
empty value-module stub (green) and proves a mutated child `#[path]` fails
closed.
